# Time-Series Analysis: NIFTY-50 Stock Price Dataset

## Overview
An exploratory quantitative research project analyzing historical ICICI Bank stock-market data from the NIFTY-50 dataset. The project investigates time-series patterns and experiments with statistical and deep learning models to forecast Volume Weighted Average Price (VWAP).

## Objectives
- Analyze financial time-series patterns and trends.
- Examine stationarity and autocorrelation.
- Engineer lag-based features for forecasting.
- Compare statistical models with recurrent neural networks.
- Evaluate prediction errors and identify modeling limitations.

## Methods
- Exploratory Data Analysis (EDA)
- Moving Averages, ACF, and PACF
- Augmented Dickey-Fuller (ADF) Test
- Time-Series Decomposition
- Lag-Based Feature Engineering
- Autoregressive (AR) Model
- ARIMAX
- Long Short-Term Memory (LSTM)
- Recurrent Neural Network (RNN)
- Model Evaluation using RMSE and MAE

## Tools & Libraries
- Python
- Pandas and NumPy
- Matplotlib, Seaborn, and Plotly
- Statsmodels and pmdarima
- Scikit-learn
- TensorFlow/Keras
- Jupyter Notebook

## Key Learning
Applied statistical methods and forecasting models to financial time-series data, focusing on model evaluation, sequential patterns, and the limitations of predictive analysis.
